# Coze Skill: App自动运营

这是 [App Autopilot](../README.md) 的 **Coze 技能版本**，可直接在 [扣子（Coze）](https://www.coze.cn) 平台中使用。

## 快速开始

### 方式一：直接安装（推荐）

在扣子平台「我的技能」中搜索 **App自动运营** 即可安装使用。

### 方式二：手动导入

1. 将 `coze-skill/` 目录下的所有文件打包为 `.zip`
2. 在扣子平台创建技能时选择「上传 zip」
3. 上传打包好的文件即可

## 使用方式

安装后，在对话中直接用自然语言描述你的需求即可触发：

- **求职投递**：「帮我自动投 Boss 直聘」「每天帮我投递 20 个运营岗」
- **社交运营**：「帮我代运营 Soul」「每 45 分钟检查一下消息」

## 使用前准备

1. **添加云手机/云电脑**：技能依赖 `mobile_use` 来操作 App
2. **创建配置文件**：首次使用时，技能会引导你创建配置（参考 `configs/` 下的模板）
3. **配置邮箱**：用于接收异常通知和重要消息提醒

## 配置说明

配置文件存放在 `./autopilot_configs/` 目录下：

| 文件 | 用途 |
|------|------|
| `job_config.yaml` | 求职投递规则（打分维度、过滤词、通知配置） |
| `social_config.yaml` | 社交运营规则（人设、回复风格、打招呼策略） |

所有配置均使用 YAML 格式，参照 `configs/` 下的模板填写即可。

## 与框架版本的关系

- **本目录（coze-skill）**：Coze 平台专用技能，通过自然语言触发，依赖扣子的 `mobile_use`、`calendar`、`email` 等内置工具
- **根目录的 Python 框架**：通用框架，可集成任何自动化工具，适合开发者自定义扩展

两者共享相同的业务逻辑设计理念，可根据使用场景选择。
